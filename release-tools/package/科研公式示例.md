# 科研公式示例

这份文档演示墨读内置的公式排版：化学式、物理化学公式、单位与数值、矩阵和多行公式。所有公式都在本机离线排版，不需要联网。按 `Ctrl+2` 切换到分栏视图，可以对照左边的写法和右边的效果。

## 1. 化学式与反应方程式

化学式写在 `\ce{…}` 里（mhchem 的写法）：水 $\ce{H2O}$、硫酸 $\ce{H2SO4}$、氢氧化钙 $\ce{Ca(OH)2}$、硫酸根 $\ce{SO4^2-}$、铵根 $\ce{NH4+}$、四氨合铜离子 $\ce{[Cu(NH3)4]^2+}$、五水硫酸铜 $\ce{CuSO4*5H2O}$。

离子电荷写在 `^` 后面：$\ce{Fe^3+}$、$\ce{Fe^{3+}}$。按 mhchem 的规则，元素后面的数字是下标，所以 `\ce{Fe3+}` 显示为 $\ce{Fe3+}$。

不写公式时，正文里也可以直接写下标和上标：H~2~O、CO~2~、Fe^3+^、SO~4~^2-^；数字之间的 `~` 表示范围，例如“反应 2~3 小时，产率 85~90%”。

$$\ce{2H2 + O2 -> 2H2O}$$

$$\ce{N2 + 3H2 <=>[催化剂][高温、高压] 2NH3}$$

$$\ce{CaCO3 ->[\Delta] CaO + CO2 ^}\qquad \ce{Ag+ + Cl- -> AgCl v}$$

$$\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}$$

平衡偏向一侧、双向反应与聚集状态：

$$\ce{A <=>> B}\qquad \ce{A <<=> B}\qquad \ce{CO2(g) + H2O(l) <=> H2CO3(aq)}$$

核素、核反应与自由基：

$$\ce{^{235}_{92}U + ^{1}_{0}n -> ^{141}_{56}Ba + ^{92}_{36}Kr + 3^{1}_{0}n}$$

$$\ce{O2 + e- -> O2^{.-}}\qquad \ce{HO^.}$$

有机物的化学键：

$$\ce{CH3-CH2-OH}\qquad \ce{CH2=CH2}\qquad \ce{HC#CH}$$

花括号里是正体文字，不按化学式解析：

$$\ce{{Glucose} + O2 ->[{葡萄糖氧化酶}] {Gluconolactone} + H2O2}$$

## 2. 物理化学

酸的电离常数与 pH：

$$K_\mathrm{a}=\frac{[\ce{H+}][\ce{A-}]}{[\ce{HA}]},\qquad \mathrm{pH}=-\lg[\ce{H+}]$$

阿伦尼乌斯方程与能斯特方程（带编号，可以在正文中引用）：

$$k=A\exp\left(-\frac{E_\mathrm{a}}{RT}\right)\tag{1}\label{eq:arrhenius}$$

$$E=E^\circ-\frac{RT}{nF}\ln Q\tag{2}\label{eq:nernst}$$

由式 $\eqref{eq:arrhenius}$ 可知，温度升高时速率常数增大；式 $\eqref{eq:nernst}$ 给出电极电势与浓度的关系。

吉布斯自由能与平衡常数：

$$\Delta_\mathrm{r}G_\mathrm{m}^\circ=-RT\ln K^\circ=\Delta_\mathrm{r}H_\mathrm{m}^\circ-T\Delta_\mathrm{r}S_\mathrm{m}^\circ$$

一级反应的积分速率方程：

$$\ln\frac{[\mathrm{A}]_0}{[\mathrm{A}]_t}=kt,\qquad t_{1/2}=\frac{\ln 2}{k}$$

## 4. 矩阵与多行公式

薛定谔方程与久期方程：

$$\hat{H}\psi=E\psi,\qquad \hat{H}=-\frac{\hbar^2}{2m}\nabla^2+V$$

$$\begin{vmatrix} H_{11}-ES_{11} & H_{12}-ES_{12} \\ H_{21}-ES_{21} & H_{22}-ES_{22} \end{vmatrix}=0$$

连续反应 $\ce{A -> B -> C}$（速率常数分别为 $k_1$、$k_2$）的速率方程：

$$\begin{aligned}
\frac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t} &= -k_1[\mathrm{A}] \\
\frac{\mathrm{d}[\mathrm{B}]}{\mathrm{d}t} &= k_1[\mathrm{A}]-k_2[\mathrm{B}] \\
\frac{\mathrm{d}[\mathrm{C}]}{\mathrm{d}t} &= k_2[\mathrm{B}]
\end{aligned}$$

分段函数：

$$F(t)=\begin{cases} 0, & t<0 \\ 1-e^{-\lambda t}, & t\ge 0 \end{cases}$$

## 5. 自定义命令

在任意一个公式里定义的命令，后面的公式都能使用：

$$\newcommand{\conc}[1]{\left[\mathrm{#1}\right]}\conc{A}_t=\conc{A}_0\,e^{-kt}$$

例如 $\conc{B}_\infty=\conc{A}_0$。
